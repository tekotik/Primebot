# PrimeAvtoExport Telegram Bot (Primebot)

Telegram-бот для поиска и мониторинга автомобилей с закрывающимися timed-торгами (**IAAI** и **Copart**).

## 🚀 Возможности
- ⚡ **Команда `/timed [марка] [модель]`**:
  - Быстрый поиск актуальных лотов с timed-торгами.
  - Строгое отображение времени до закрытия (`countdown.text_hours`) из блока *Bid Information*.
  - Поле `auction_date` для timed-лотов скрыто (не показывает некорректную дату живых торгов).
- 📅 **Команда `/day <дд.мм.гггг> [марка] [модель]`**:
  - Поиск аукционных лотов на конкретную дату.
- ⚙️ **Команда `/filter`**:
  - Интерактивный выбор типа титула (*Clean*, *Salvage*) и минимального года выпуска.
- ☀️ **Команда `/autocollect [марка] [модель]`**:
  - Автоматическая рассылка подборки машин **1 раз в день**.
- 🔗 **Карточки лотов**:
  - Реальная фотография лота.
  - Год, марка, модель, серия.
  - Текущая ставка и цена «Buy Now».
  - Номер лота (`lot_id`) и штат.
  - Кнопка «🔗 Лот на аукционе» (прямая ссылка).
  - Кнопка «💰 Расчёт под ключ» (официальный калькулятор `https://primeavtoexport.com/staging/ru/calculator/?lot={lot_id}`).
- 🛡️ **Кэширование 5 минут**:
  - Идентичные запросы к API кэшируются на 5 минут для бережного отношения к серверу и мгновенного ответа.

## 🛠️ Установка и запуск

### 1. Установка зависимостей
```bash
cd bot
pip install -r requirements.txt
```

### 2. Запуск бота
Укажите ваш токен от BotFather в переменной `TELEGRAM_BOT_TOKEN`:

```bash
export TELEGRAM_BOT_TOKEN="123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ"
python bot.py
```

Или в одну строку:
```bash
TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН" python bot.py
```

## 🌐 Конфигурация окружения (Staging / Production)

По умолчанию бот настроен на **staging**:
- Базовый URL: `https://primeavtoexport.com/staging`
- Фид API: `https://primeavtoexport.com/staging/api/bot-feed.php`
- Статичный ключ: `5f17153da0663379d06efa746e2fe65a`

### 🚀 Переход на боевой сервер (Production):
Для перевода бота на прод путь `/staging` убирается автоматически, а ключ задается через переменную окружения `PRIME_FEED_KEY`:

```bash
export PRIME_ENV="production"
export PRIME_FEED_KEY="ВАШ_БОЕВОЙ_КЛЮЧ_ИЗ_BOT_CONFIG_PHP"
export TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_БОТА"
python bot.py
```

## ⏱️ Особенности расчёта времени (Live Countdown)
1. **Динамический пересчет**: бот кэширует сырой ответ сервера на 5 минут, но строку оставшегося времени (`22ч 16м`) **пересчитывает в реальном времени из поля `countdown.close_utc`** в момент отправки каждой карточки. Время никогда не «залипает».
2. **Исключение `auction_date`**: для лотов `is_timed: true` поле `auction_date` живых торгов намеренно скрыто и не сбивает покупателя с толку.
